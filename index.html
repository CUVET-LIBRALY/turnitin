บริการตรวจสอบความซ้ำซ้อนทางวิชาการ (Turnitin)

ห้องสมุดและศูนย์เอกสารการสัตว์ คณะสัตวแพทยศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย

ตรวจสอบใบรับรอง (QR)

ยกระดับความน่าเชื่อถือทางวิชาการ ด้วยระบบใบรับรอง QR Code ออนไลน์

ให้บริการตรวจสอบค่าความซ้ำซ้อน (Similarity Index) และค่าตรวจจับเนื้อหา AI (AI Writing Detection) สำหรับนิสิตและบุคลากรคณะสัตวแพทยศาสตร์ โดยตั้งค่าแบบ No Repository (ไม่จัดเก็บไฟล์ลงฐานข้อมูล)

สร้างข้อความส่งขอตรวจ

ขั้นตอนการขอรับบริการ (3 ขั้นตอนง่ายๆ)

แยกขั้นตอนชัดเจนระหว่าง "รอบตรวจเพื่อแก้ไข" และ "รอบขอออกใบรับรองฉบับจริง"

1

ส่งไฟล์และรายละเอียดทางอีเมล

ส่งไฟล์เอกสาร (.doc, .docx หรือ .pdf) มาที่อีเมลห้องสมุด พร้อมระบุข้อมูลให้ครบถ้วน:

  • • ชื่อ-นามสกุล และรหัสนิสิต
  • • ชื่อบทความ / วิทยานิพนธ์ / โครงงาน
  • • อีเมลอาจารย์ที่ปรึกษา / อาจารย์ประจำวิชา
  • • ประเภทคำขอ: Draft หรือ Official
2

รอบตรวจแก้ไข (Draft Check)

หากค่าความซ้ำซ้อนยังสูงกว่าเกณฑ์ นิสิตสามารถปรับปรุงเนื้อหาและตอบกลับอีเมลเดิมเพื่อส่งตรวจซ้ำได้จนกว่าจะผ่านเกณฑ์

หมายเหตุ: ผลตรวจรอบ Draft จะส่งกลับให้ นิสิตเพียงผู้เดียว เพื่อนำไปแก้ไข (ยังไม่ส่งถึงอาจารย์ และไม่สามารถใช้ยื่นส่งงานได้)
3

ขอใบรับรองฉบับจริง (Official)

เมื่อผลผ่านเกณฑ์แล้ว ให้ตอบกลับอีเมลเดิมเพื่อขอ "ออกใบรับรองผลฉบับจริง" ห้องสมุดจะแนบหน้าปกรับรองที่มี QR Code ไว้หน้าแรก

การส่งมอบ: ห้องสมุดจะส่งไฟล์ฉบับสมบูรณ์ให้นิสิต พร้อม สำเนาถึง (CC) อาจารย์ที่ปรึกษาโดยตรง เพื่อยืนยันความถูกต้อง

การแสดงผลค่า AI Writing Detection

ในใบรับรองจะแสดงทั้งค่า Similarity Index (%) และค่า AI Writing Detection โดยตามมาตรฐานของระบบ Turnitin หากตรวจพบเนื้อหาเข้าข่าย AI ต่ำกว่า 20% (1%–19%) ระบบจะแสดงสัญลักษณ์ < 20% (*%) และสำหรับเอกสารภาษาไทยจะแสดงเป็น N/A

ระบบตรวจสอบความถูกต้องผ่าน QR Code

เอกสารฉบับรับรองผลอย่างเป็นทางการจะมี รหัสอ้างอิง (Ref. ID) และ QR Code ประจำเอกสาร คณาจารย์สามารถสแกนเพื่อตรวจสอบค่าเปอร์เซ็นต์จริงและประวัติการส่งตรวจย้อนหลังทั้งหมดจากฐานข้อมูลห้องสมุดได้ทันที

SELF-SERVICE HELPER

เครื่องมือสร้างข้อความส่งอีเมลขอตรวจ Turnitin (สำหรับนิสิต)

กรอกข้อมูลด้านล่างเพื่อสร้างข้อความส่งอีเมลที่ถูกต้องครบถ้วน ลดความล่าช้าในการตรวจสอบ

ส่งถึงอีเมล:
หัวข้ออีเมล (Subject)
เนื้อหาอีเมล (Email Body)
สำหรับเจ้าหน้าที่: ข้อความประกาศประชาสัมพันธ์สำเร็จรูป (สำหรับโพสต์ Facebook / LINE / Instagram)
แคปชันประชาสัมพันธ์ 2 ภาษา (พร้อมคัดลอกโพสต์)
